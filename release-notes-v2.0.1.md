# v2.0.1 - Окно по размеру интерфейса и экрана

> **Конвертер валют на основе официальных курсов ЦБ РФ**
> Go реализация проекта [CurRate](https://github.com/bivlked/CurRate) с XML API ЦБ РФ и desktop UI на Wails

---

## Что исправлено

### Интерфейс помещается в окно без прокрутки

После v2.0.0 в окне иногда появлялась вертикальная прокрутка. Например, после конвертации на выходной день с референсной датой результат уходил вниз за край окна.

Оказалось, что я неправильно считал размер. В Wails ширина и высота окна задаются вместе с рамкой и заголовком, поэтому из 360×758 самой странице доставалось около 345×720. А интерфейсу в худшем случае нужно 361×782: месяц в 6 недель, выходной день, большая сумма и строка сравнения с референсом.

Теперь окно 376×822 вместе с рамкой, внутри около 361×784. Вёрстку я не менял. Суммы до 999 999 999 999,99 помещаются целиком.

### Окно не уходит за край низкого экрана

Размер окна менять нельзя, и на низком экране это мешало. На 1280×720 или на 1920×1080 при масштабе 125% и выше окно не помещалось по высоте, и низ с результатом оказывался за краем экрана. Прежнее окно 758 px там тоже не помещалось, так что проблема старая.

Теперь при запуске программа смотрит, сколько места есть на мониторе, где открылось окно, без панели задач и с учётом масштаба. Если 822 px не помещаются, окно становится ниже, а интерфейс можно прокрутить колесом мыши. На обычных экранах всё как раньше.

## Безопасность

Обновил зависимости: `labstack/echo/v4` 4.15.3 → 4.16.1, `golang.org/x/net` 0.56.0 → 0.60.0 и `golang.org/x/crypto` 0.53.0 → 0.57.0 приходят от Wails, а `golang.org/x/sys` 0.46.0 → 0.48.0 теперь нужна и самой программе, через неё окно узнаёт размер экрана. Так закрылись предупреждения Dependabot по echo. На саму программу они не влияли: echo нужен Wails только для dev-сервера и в собранный exe не попадает.

## Технические детали

- Новый пакет `internal/window`: `FitHeight` считает высоту окна по рабочей области монитора и DPI, `WorkArea` получает их через Win32 (`MonitorFromWindow`, `GetMonitorInfoW`, `GetDpiForWindow`).
- Окно ищется по своему классу `CurRateWindow` и PID процесса, поэтому второй запущенный экземпляр не мешает.
- Монитор берётся у самого окна, а не у курсора: Windows может открыть окно и на другом мониторе.

## Обновление с v2.0.0

1. Скачайте `CurRate.exe` из Assets ниже, контрольная сумма лежит в `checksums.txt`
2. Замените старый файл
3. Запустите приложение

Пользовательские данные (`%APPDATA%/CurRate/user.json`) сохраняются.
